# learn-vibe-code

A personal repo where I build small projects while following the [easy-vibe](https://github.com/datawhalechina/easy-vibe) course by Datawhale, which is about learning to build software with AI ("vibe coding").

Each project lives in its own folder with its own README and setup steps.

## Projects

| Project | Description | Tech |
| --- | --- | --- |
| [flappy-bird](flappy-bird/) | An 8-bit style Flappy Bird game with keyboard and mouse controls, a Game Over screen and restart | Python, pygame-ce |
| [wrnrs](wrnrs/) | First Date Deck, a conversation card game for breaking the ice, based on the questions from We're Not Really Strangers (fan project, just for fun). [Play it online](https://longle0702.github.io/learn-vibe-code/wrnrs/) | HTML, CSS, vanilla JavaScript |

## Working with this repo

- Python projects use a local virtual environment (`.venv`) inside their own folder. It is not committed, so recreate it from the project's `requirements.txt`. See each project's README for the exact commands.
- New projects are added as new top-level folders and listed in the table above.
